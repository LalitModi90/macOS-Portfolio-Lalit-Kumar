## 🛠️ Architecture & Tech Stack

- **Core Technologies**: [React 18](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite](https://vitejs.dev/)
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs/)
- **Styling**: [UnoCSS](https://uno.antfu.me/) & [Tailwind CSS](https://tailwindcss.com/) with native CSS glassmorphism
- **Animations & Interactivity**: [Framer Motion](https://www.framer.com/motion/)
- **Markdown & Code Rendering**: [React Markdown](https://github.com/remarkjs/react-markdown), [KaTeX](https://katex.org/), [Remark GFM](https://github.com/remarkjs/remark-gfm)
- **Icons & Graphics**: SF Symbols, [Iconify](https://iconify.design/), and custom SVG assets

---

## 🌟 Interactive Highlights

- **Window Management**: Multi-window system with fluid dragging, resizing, minimizing, and focus switching.
- **Dock & Launchpad**: macOS-style physics-based magnification dock and organized app launchpad.
- **Siri AI Assistant**: Interactive voice/text assistant powered by AI.
- **Terminal & VS Code**: Built-in terminal emulator and web-based VS Code project explorer.
- **Media & Customization**: Spotify / Apple Music style audio player, anime & dynamic wallpapers, and dark/light mode toggle.
- **Mobile Responsive**: Adaptive iOS mobile mode optimized for smartphones and tablets.
