# macOS Tahoe Portfolio — Lalit Kumar

A personal portfolio web application crafted with the elegance and aesthetic of Apple's macOS Tahoe / Liquid Glass design language.

Developed by **[Lalit Kumar](https://github.com/LalitModi90)** (Software Development Engineer).

---

## ✨ Features

- 🍎 **macOS Desktop Experience**: Realistic macOS menu bar, dock animations, launchpad, spotlight search, control center, and dynamic island.
- 💻 **Interactive Apps**:
  - **About Me / Safari**: Explore personal background, education, experience, achievements, and tech stack.
  - **Projects Showcase**: Interactive window browsing full-stack and software engineering projects.
  - **Terminal**: Interactive shell with custom commands and portfolio navigation.
  - **System Settings**: Customizable appearance (dark/light mode), wallpapers, sound effects, and preferences.
  - **Siri Voice Assistant**: AI-powered assistant with intelligent voice and text interactions.
  - **Music Player & Widgets**: Apple Music style audio player, live clock, calendar, and weather widgets.
- 📱 **Mobile Responsive**: Adaptive iOS / mobile-friendly interface for smaller screens.
- ⚡ **PWA Ready**: Installable as a progressive web app on desktop and mobile.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [pnpm](https://pnpm.io/) (v9+) or `npm`

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/LalitModi90/macOS-Portfolio.git

# Navigate to the project directory
cd macOS-Portfolio

# Install dependencies
pnpm install

# Start local development server
pnpm dev

# Build for production
pnpm build
```
